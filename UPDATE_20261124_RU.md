# TheAppleBook — обновление 24.11.2026

## Что изменено
- Переработано меню: кнопка ☰ открывает выдвижную панель на ПК и телефоне; затемнение закрывает её.
- Пункты меню приведены к запрошенным разделам; профиль, статус, репутация и выход расположены в нижней части меню.
- После авторизации открывается раздел «Чаты». На мобильном устройстве сначала показывается список диалогов; после выбора чата — переписка с кнопкой возврата.
- Добавлен отдельный список контактов.
- Реализованы создание групп/каналов через RPC, список, открытие группового чата, отправка сообщений, Realtime-обновления, реакции, загрузка файлов и голосовых сообщений в группах, подписка на публичные каналы, публикации администраторов, счётчики подписчиков/просмотров, приглашение участников и управление ролями/удалением участников.
- Добавлены WebRTC аудио/видеовызовы из шапки личного чата, входящий вызов, принятие/отклонение, выключение микрофона/камеры и завершение. Это базовая реализация сигнализации; TURN и проверка на реальных сетях остаются обязательными перед публичным запуском.
- Обновлены стили и версия Service Worker, чтобы браузер не продолжал использовать старый кеш.

## SQL
Так как базовая миграция групп/каналов уже применялась ранее, в Supabase SQL Editor нужно выполнить только `migrations/20261124_community_owner_compat.sql`. Она добавляет совместимость `owner_id`/`created_by` и RPC для управления участниками. Не запускайте повторно базовую миграцию, если таблицы уже существуют.

Для чистой базы сначала выполните `migrations/20261124_groups_channels_calls.sql`, затем `migrations/20261124_community_owner_compat.sql`.

## Ограничения звонков
Звонки используют WebRTC и Supabase Realtime broadcast для сигнализации. В коде указаны STUN-серверы. Для надёжной работы между разными сетями и за NAT необходим TURN-сервер; его учётные данные нужно добавить в конфигурацию RTCPeerConnection. Вызовы требуют HTTPS (или localhost) и разрешения браузера на микрофон/камеру. Перед публичным запуском следует провести тесты на двух устройствах и разных сетях.
